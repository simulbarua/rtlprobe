# SHA-1 specification store

The August 2015 edition of FIPS 180-4 defines the block compression algorithm. The included requirements refer to pre-padded input blocks. Source coordinates refer to secworks/sha1 revision 50f82f4ca2f8194fd47d8360270ac7dd141d53d1. Both checkpoints observe digest values. A repeated first-block comparison in the testbench leaves the final double-block digest unchecked.
